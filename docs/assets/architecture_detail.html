Accuracy and drift answer different questions. Accuracy compares each prediction with the actual outcome for that same record. In a real deployment, match records by customer or prediction ID and the target period, using the model version that made the original prediction. The current notebook demonstrates this with paired predictions and known charges on held-out Kaggle rows. Predictions and actuals are columns in the same evaluation table, not two separate reference/current datasets. The notebook also supplies a similarly labelled training reference batch to compare regression results. Its combined baseline report includes both regression quality and drift checks.

Drift does not need actual outcomes. It compares corresponding feature or prediction distributions in two batches. Here the reference contains training features and predictions; the current batch is either the held-out test split or shifted, simulated production records with new predictions. The simulated records have no known charges, so they cannot support an accuracy calculation. Detected drift does not prove worse accuracy, and undetected drift does not prove that predictions are accurate. Reference/current describe batches; prediction/actual describe values within each record.
